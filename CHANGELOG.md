# Changelog

- `MatchData.next` follows PCRE2's boolean return convention; `Regex.decode` checks destination capacity before decoding.
- Shared-library dependents resolve the package build artifact; installed artifacts retain prefix-relative loader paths.
- COFF core builds decorate the in-core POSIX wrapper's calls as local exports.
- Cross-target builds choose default linkage from each target; explicit `-Dlinkage` applies to every target.
- Character tables passed to `CompileContext` remain borrowed by PCRE2 and must outlive patterns compiled with them.
- `Regex.substitute` invalidates captures before the call and returns its count separately; `.matched` preserves existing captures.
- `Regex.enumerateCallouts` requires a non-null callback.
- Serialization distinguishes rejected streams from allocation failures; `Regex.decode` bounds its destination before calling PCRE2.
- UTF validity errors map to the correct outcome at 8-, 16-, and 32-bit widths.
- With JIT disabled, compile reports PCRE2's JIT refusal and JIT stack creation returns null; no interpreter fallback is reported as JIT.
- Callout returns use PCRE2's sign semantics; the callback and its data remain caller-owned borrows.
- POSIX exposes its `-1` unset marker, respects capture-array capacity, and reports bad parentheses as `REG_EPAREN`.
- PCRE2-allocated result blocks document their matching release functions; copy buffers include space for the terminating NUL.
- DFA results use `MatchData`'s offset vector, and name-table decoding respects each code-unit width.
- `Regex.match` clears readable captures before each attempt, so a failed match cannot expose stale offsets.
- `Regex.nameAt` returns declared names from the width-aware, alphabetical name table.
- System mode uses the installed header with the installed library and applies the requested linkage consistently.
- `version(buffer)` writes a NUL-terminated version into caller-owned storage and refuses short buffers without writing.
- Unicode core code at widths 8, 16, and 32 is built into the artifact; the selected code-unit width controls the typed facade.
- The package publishes the `pcre2` module, `pcre2-8` library, 8-bit `pcre2-posix` wrapper, and `pcre2test` utility.
- Dynamic linkage is the default on GNU-libc targets and static elsewhere; supported targets accept `-Dlinkage`.
- `-fsys=pcre2-8` links an installed library and translates its installed header without compiling bundled sources.
- The lazy `sljit` dependency and `-Dsupport_jit` option are removed; bundled builds set `SUPPORT_JIT=0` and fetch no build dependency.
- The typed facade wraps the translated PCRE2 header and exposes the raw C declarations through `c`.
